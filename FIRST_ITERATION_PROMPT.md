# Первое задание для Codex — итерация 0

Прочитай AGENTS.md, docs/TECHNICAL_SPEC.md, docs/DEVELOPMENT_PLAN.md и docs/PROGRESS.md.

Реализуй ТОЛЬКО итерацию 0: минимальный запускаемый Django 5.2 LTS проект с `config`, пустым приложением `crm`, SQLite, базовыми настройками, `.gitignore`, `requirements.txt`, `README.md` с инструкцией локального запуска и одним минимальным smoke test. Подключи приложение в INSTALLED_APPS. Не создавай модели CRM, бизнес-формы, страницы клиентов, сделок или задач. Не копируй код из сторонних CRM-репозиториев.

Перед изменениями коротко перечисли план и критерии готовности. После изменений выполни `python manage.py check`, `python manage.py test` и `python manage.py makemigrations --check --dry-run`; проверь отсутствие секретов и локальной базы в отслеживаемых Git-файлах. Если запуск невозможен, честно объясни почему. Обнови README.md и docs/PROGRESS.md с фактическими результатами, изменёнными файлами и ограничениями. Не начинай итерацию 1 без моего разрешения.
