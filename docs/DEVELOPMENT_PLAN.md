После каждого этапа: демонстрация результата, автоматические проверки, ручная проверка, обновление README и PROGRESS. Следующий этап — только после согласования.

## Обязательный отчёт Codex
- Цель итерации и выполненные требования.
- Список изменённых файлов.
- Команды проверок, коды завершения и краткий результат.
- Что проверено вручную и что не проверено.
- Известные проблемы и риски.
- Следующий минимальный шаг, без его реализации.
