## Работа с Word

Откройте DOCX в Microsoft Word. Основной стиль Normal: Times New Roman 14 пт, 1,5 строки, отступ 1,25 см, выравнивание по ширине, 0 пт до/после. А4, поля 3 / 1,5 / 2 / 2 см. Times New Roman Cyr и Times New Roman в среде не установлены; в DOCX указан совместимый Times New Roman, при рендеринге LibreOffice использует замену Liberation Serif. Файлы шрифтов не добавляются.

Стили Heading 1–3 предназначены для будущих глав, подразделов и параграфов; связан многоуровневый десятичный список, Heading 1 начинает страницу. Названия глав не заданы. VKR Structural — нейтральные структурные места, отдельный стиль без включения в оглавление; VKR Figure — подпись под рисунком; VKR Table — название над таблицей; VKR Bibliography — запись источника; List Number / List Bullet — настоящие списки; VKR Appendix — приложение; VKR Title — титул; VKR Placeholder — место заполнения. Формат этих стилей требует сверки с рекомендациями.

Титульные реквизиты — редактируемые элементы управления содержимым без персональных данных. Их расположение предварительное; обязательный официальный состав неизвестен. Организационные поля оставлены для заполнения после сверки образца. Тема воспроизведена полностью.

Содержание содержит настоящее поле `TOC \o "1-3" \h \z \u`, без записей глав. После согласования структуры применяйте Heading 1–3 и обновите поле через контекстное меню → «Обновить поле» → «Обновить целиком». Для включения структурных заголовков потребуется согласовать правила и настройки оглавления; сейчас они туда автоматически не входят.

Нижний колонтитул содержит поле PAGE по центру; для первой страницы отдельный пустой колонтитул. Титул учитывается: содержание получает номер 2. Номера не набраны текстом. Формулы в дальнейшем вставляются через Вставка → Уравнение (OMML); задан Cambria Math, образцы формул не добавлены.
